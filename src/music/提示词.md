# 背景音乐提示词

每档景一套音乐，用 Web Audio 实时合成（`engine.ts` + `presets.ts`），不放做好的曲子。
在每档的「提示词」下面写就行，中文英文都可以，写得像给 Suno 的那样也可以。

## 写提示词时可以想的几件事

- **乐器**：两三种就够，比如康特勒琴泛音、钢片琴、气声持续音。乐器越具体，合成出来越像。
- **情绪和画面**：这一档让人想到什么。
- **快慢和疏密**：音之间隔多久，有没有长的空白。
- **要什么、不要什么**：比如「没有旋律」「不要鼓」。
- **和磨声的关系**：前几档磨声和蹄声是主角，音乐只是一点点；越往后音乐越满。可以写这一档音乐该占多少。

下面这些是游戏自己会做的，不用写进提示词：

- 音乐的拍子会慢慢贴近玩家的步频，走得越稳，越多琴音落在步子上；停下来以后音乐变稀。
- 景升档时，两档的音乐会交叉淡变过去。
- 磨越先进，石磨和蹄声越轻（这一步还没做）。
- 试听：网页加 `?music` 会跟着当前的景自动选曲；`?music=jinmu` 只放一首。离线渲染在 `~/Desktop/拉磨图标/音乐场景/试听/`。

截图都在 `~/Desktop/拉磨图标/音乐场景/`，每档两张，一张朝前看，一张转头看磨。
